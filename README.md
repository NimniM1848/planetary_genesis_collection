# 惑星系創造

〜創って、見守って、集める〜

恒星と、惑星のもとになる円盤の条件を決めて、惑星系ができる様子を見守り、できた惑星と惑星系を図鑑に集めるゲームです。スマホでもパソコンでも遊べます。

## あそびかた

### 1. 創る
- 開くと、ランダムな条件が用意されています。そのまま「惑星系をつくる」を押せます。
- 「条件を引き直す」を押すと、条件が変わります。画面の「初期の円盤」には、その条件でできる円盤の形（ガス・固体の濃淡、リングやギャップ、スノーライン、ハビタブルゾーン）と、惑星の種ができる位置が出ます。気に入った円盤で、「つくる」を押しましょう。
- プリセット（標準・巨星の多い系・ホットジュピター系・氷巨星の多い系）を選んだり、「詳細設定」で、恒星の重さや明るさ、金属量、円盤の重さ・広さ・寿命などを、自分で決めたりもできます。

### 2. 見守る
- 円盤の中に惑星の種が生まれ、材料を集めて育ちます。ぶつかって一つになったり、ガスを集めて巨大なガス惑星になったり、弾き飛ばされたり…。その様子を、上から見守ります。
- 「一時停止」して、惑星をタップすると、その惑星の情報（重さ、大きさ、温度、組成など）が、図の上に出ます。
- できごと（合体、放出など）が起きるときは、自動でゆっくり再生になります。できごとの一覧を押すと、その時に戻れます。
- 速度、ハビタブルゾーンの表示、効果音は、切り替えられます。

### 3. 集める
- 完成した惑星と惑星系は、自動で図鑑に登録されます。
- 珍しい組み合わせほど、希少度の★が多くなります（★1〜★5）。
- 惑星図鑑は、惑星の分類と特徴タグのマスを埋めていく形です。惑星系図鑑では、集めた惑星系を、もう一度見たり、共有したりできます。

### 4. 共有する
- 結果は、画像やリンクにして、X などで共有できます。
- リンクを開いた人は、同じ条件の惑星系を、そのまま再現できます。

## 図鑑のデータについて
図鑑のデータは、**あなたのブラウザの中にだけ**保存されます。サーバーには送りません。

- ブラウザのデータを消すと、図鑑も消えます。
- 別のブラウザや別の端末とは、共有されません。
- 同じアドレスで開いたときだけ、図鑑が見えます。

## ご注意
- このゲームは、惑星のでき方を、やさしく近似した**簡易モデル**で計算します。実際の惑星系のでき方を、正確に再現・予測するものではありません。
- ゲームが更新されると、計算が変わることがあります。そのとき、共有リンクや図鑑の「もう一度見る」で作り直した結果は、以前と変わる場合があります（図鑑に登録済みの、最終結果は残ります）。
- ブラウザの種類によって、数値の最後の桁が、わずかに違うことがあります（結果の中身は、同じです）。
